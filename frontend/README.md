# SupeRR Selector — Cricket Pressure Intelligence Dashboard
## Production Frontend (React + Vite + TypeScript + Tailwind CSS)

A modern, responsive, high-performance cricket analytics intelligence dashboard developed for **Rajasthan Royals SupeRR Selector Season 2**.

The platform is designed to identify and rank the **Top 10 Most Reliable Batters** and **Top 10 Most Reliable Bowlers** under match pressure, powered by historical IPL and T20 International (T20I) ball-by-ball delivery records (2022 onwards).

---

### Key Technical Architecture

- **Zero-Backend Vercel Deployment**: Operates 100% statically on Vercel or GitHub Pages without requiring a persistently running Python backend.
- **Source of Truth**: All analytics, metrics, Bayesian shrinkage ratings, confidence intervals, and case studies are generated by the validated Python analytics pipeline (`src/ranking_engine.py`) and statically serialized to `frontend_data.json`.
- **Framework & Libraries**:
  - **React 18** with **TypeScript** for strict type safety.
  - **Vite 6** for instantaneous HMR and optimized production bundling.
  - **Tailwind CSS 3** with custom glassmorphism surfaces and dark sports-analytics theme.
  - **Recharts** for interactive SVG charts (Dual timeline, Radar charts, Distribution histograms).
  - **Lucide React** for modern iconography.

---

### Dashboard Screens & Capabilities

1. **Overview Dashboard** (`/#overview`):
   - Executive statistics: 200,999 deliveries, 883 matches, 70,575 pressure balls, 291 qualified players.
   - Quick-access feature cards for Rank 1 Batter (Yashasvi Jaiswal) and Rank 1 Bowler (Jamie Overton).
   - Interactive 4-tier pressure score distribution chart.
   - Core analytical pillars breakdown.

2. **Batting Leaderboard** (`/#batting`):
   - Certified Top 10 Batters and expandable cohort of all 135 qualified batters.
   - Sorting by Rank, Reliability Score, Pressure Strike Rate, Delta Strike Rate, Context Runs Added ($RA100$), Dot %, Boundary %, and Pressure Balls.
   - Search filter by player name or franchise/country.
   - Visual 95% Confidence Interval whiskers bar on every row.
   - Direct CSV download for official Top 10 and full cohort.

3. **Bowling Leaderboard** (`/#bowling`):
   - Certified Top 10 Bowlers and expandable cohort of all 156 qualified bowlers.
   - Sorting by Rank, Reliability Score, Pressure Economy, Delta Economy, Runs Prevented ($RP6$), Wickets, Dot %, and Overs.
   - Search filter by bowler name or franchise/country.
   - Visual 95% Confidence Interval whiskers bar on every row.
   - Direct CSV download for official Top 10 and full cohort.

4. **Player Comparison** (`/#comparison`):
   - Interactive head-to-head matchup tool (Batter vs Batter or Bowler vs Bowler).
   - Side-by-side reliability ratings, archetypes, and key strength highlights.
   - Dual 5-dimensional skill Radar overlay chart.
   - Direct statistical comparison table with automatic advantage highlights.

5. **Pressure Explorer** (`/#explorer`):
   - Ball-by-ball timeline of the **IPL 2023 Final** (CSK vs GT rain-shortened chase to 171).
   - Interactive Over scrubber (Overs 1 through 15) with detailed delivery tables.
   - Visual explanation of reachability tension logic ($R \le 6 \times B$) in clutch overs.
   - 20-bin histogram comparing 1st innings vs 2nd innings pressure calibration parity.

6. **Methodology Whitepaper** (`/#methodology`):
   - Mathematical formulations for win probability uncertainty and resource projections.
   - Explanation of Empirical Bayesian Shrinkage ($n_0 = 100$ pseudo-balls) and 95% Confidence Intervals.
   - Strict zero data leakage verification proof.
   - Clear distinction between observed historical statistics and model estimates.

### Local Development

To run the development server locally:

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies (if not already installed)
npm install

# Start Vite dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

### Production Build & Preview

```bash
# Run TypeScript validation and Vite production build
npm run build

# Preview the built distribution locally
npm run preview
```

The output bundle is compiled into `frontend/dist/`.

---

### Vercel Deployment Configuration

When deploying through GitHub on Vercel:

1. **Import Repository**: Connect your GitHub repository on Vercel.
2. **Project Settings**:
   - **Root Directory**: `frontend`
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
3. **Environment Variables**: None required (completely static and self-contained).
4. **SPA Rewrites**: Handled automatically via `frontend/vercel.json`:
   ```json
   {
     "rewrites": [
       { "source": "/(.*)", "destination": "/index.html" }
     ]
   }
   ```
